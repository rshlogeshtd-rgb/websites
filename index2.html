🌍 1. Internet Overview

Understanding the global network that connects computers.

🌐

What is Internet?

The Internet is a worldwide network of interconnected computers and devices that communicate with each other.

📡

Communication

Devices communicate using standard protocols such as TCP/IP, HTTP and HTTPS.

☁️

Services

The Internet provides services such as websites, email, cloud storage, video streaming and online banking.

Example: When you open an educational website, your computer communicates with a remote server through the Internet to obtain the requested webpage.

🔗 3. URL and its Structure

URL tells the browser where a resource is located.

https://www.example.com/courses/web/index.html

HTTPS

example.com

Simple definition: A URL (Uniform Resource Locator) is the complete address used to locate a resource on the Internet.

🏷️ 4. Domain Name

A human-friendly name used to identify a website.

🏫

Example

www.harvard.edu

Instead of remembering a numerical IP address, users can remember a simple domain name.

🌐

Top-Level Domain

The final part of a domain is called the TLD.

.com → Commercial
.edu → Educational
.org → Organization
.gov → Government

🔍

DNS

DNS (Domain Name System) converts domain names into IP addresses.

💻 7. Client-Side vs Server-Side Scripting

Understanding where website code is executed.

🟦 Client-Side Scripting

The code executes inside the user's web browser.


  • Runs on user's device
  • Fast interaction
  • Used for webpage appearance and interaction
  • Can respond without contacting server every time

Examples: HTML, CSS, JavaScript

🟥 Server-Side Scripting

The code executes on the web server.


  • Runs on server
  • Processes data
  • Communicates with databases
  • Generates dynamic webpage content

Examples: PHP, Python, Java, Node.js

FeatureClient-SideServer-Side
ExecutionUser's browserWeb server
ExamplesHTML, CSS, JavaScriptPHP, Python, Java, Node.js
Database AccessNormally indirectDirectly communicates with database

Easy way to remember:
Client-side = Browser 🖥️
Server-side = Server 🗄️

Example: When you click "Login", JavaScript may check the form on your browser, while the server checks your username and password against the database.
